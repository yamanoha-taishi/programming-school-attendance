# API／ルーティング設計

- 作成日：2026-09-21
- 更新日：2026-09-22
- 対象：`実装ロードマップ.md` の未決事項「API／ルーティング設計」の決定内容。`画面一覧・遷移図.md` の各画面に、Laravel側のルート・コントローラーとInertiaページを対応づける。

## 列の意味

| 列名 | 内容 |
|---|---|
| 画面名 | `画面一覧・遷移図.md` の画面名と一致させる |
| Inertiaページ | `resources/js/pages/` 配下のコンポーネントファイル |
| パス | URL（`{}` はルートパラメータ） |
| Method | GET／POST／PUT（PATCH）／DELETE |
| ルート名 | `route('xxx.yyy')` で呼ぶ名前 |
| コントローラー＠メソッド | 担当するコントローラーとメソッド |
| 権限（guard／ミドルウェア） | どのguard・ロールが通れるか（例：`auth:guardian`、`auth:staff` かつ `full_access` のみ、など） |
| 備考 | 判断に迷った点・要確認事項など |
