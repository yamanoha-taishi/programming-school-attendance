## 画面遷移図

```mermaid
flowchart LR
  login[ログイン]

  staff_attend ~~~ guardian_attend

  subgraph 運営向け
    staff_attend[出席記録・一覧]
    staff_menu[管理メニュー]
    staff_guardian_index[保護者一覧]
    staff_guardian_create[保護者登録・編集]
    staff_student_index[生徒一覧]
    staff_student_create[生徒登録・編集]
    staff_staff_index[スタッフ一覧]
    staff_staff_create[スタッフ登録・編集]
    staff_profile[プロフィール設定]
  end

  subgraph 保護者向け
    guardian_attend[出席履歴・予定確認]
    guardian_create[欠席・遅刻・補講登録]
    guardian_profile[プロフィール設定]
  end

  login -->|運営ログイン| staff_attend
  staff_attend <-->|タブ切り替え| staff_menu
  staff_attend <-->|タブ切り替え| staff_profile
  staff_menu <-->|タブ切り替え| staff_profile
  staff_menu -->|メニュー選択| staff_guardian_index
  staff_guardian_index -->|戻る| staff_menu
  staff_guardian_index -->|登録or編集| staff_guardian_create
  staff_guardian_create -->|保存orキャンセル| staff_guardian_index
  staff_menu -->|メニュー選択| staff_student_index
  staff_student_index -->|戻る| staff_menu
  staff_student_index -->|登録or編集| staff_student_create
  staff_student_create -->|保存orキャンセル| staff_student_index
  staff_menu -->|メニュー選択| staff_staff_index
  staff_staff_index -->|戻る| staff_menu
  staff_staff_index -->|登録or編集| staff_staff_create
  staff_staff_create -->|保存orキャンセル| staff_staff_index

  login -->|保護者ログイン| guardian_attend
  guardian_attend <-->|登録orタブ切り替え| guardian_create
  guardian_attend <-->|タブ切り替え| guardian_profile
```
※運営向けのトップレベルタブは「出席記録・一覧／管理メニュー／プロフィール設定」の3つで、常にどこからでも切り替え可能（attendance_only権限の場合は「出席記録・一覧／プロフィール設定」の2タブのみ表示）

※保護者一覧／生徒一覧／スタッフ一覧の3画面はタブではなく、管理メニュー画面からの選択でアクセスする

※保護者向け画面（出席履歴・予定確認／欠席・遅刻・補講登録／プロフィール設定）は、タブ形式で常にどこからでも切り替え可能
