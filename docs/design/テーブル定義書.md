### attendances:出席記録
| 列名 | 型 | NULL許可 | 制約 | 説明 |
| --- | --- | --- | --- | --- |
| id | integer | 不可 | PK | ID |
| student_id | integer | 不可 | FK → students.id | 生徒 |
| lesson_id | integer | 不可 | FK → lessons.id | 授業回 |
| makeup_lesson_id | integer | 可 | FK → lessons.id | 補講対象回 |
| staff_id | integer | 可 | FK → staff.id | 担当スタッフ（保護者が事前連絡した時点など、スタッフ未対応の間はNULL） |
| status | enum | 可 |  | 出席結果 <br> enum('出席','欠席')|
| is_late | boolean | 不可 | default:false | 遅刻フラグ trueで遅刻 |
| makeup_type | enum | 可 |  | 補講予定 <br> enum('振替','30分前補講','補講なし','未定') |
| makeup_status | enum | 可 |  | 補講先での出席結果 <br> enum('出席','欠席')。makeup_lesson_idの授業回で実際に補講を受けたかを記録する（NULLは未記録）。makeup_typeが振替・30分前補講の場合のみ使用 |
| note | text | 可 |  | 保護者からの連絡事項（欠席・遅刻・補講登録画面の自由記入欄。複数の生徒をまとめて連絡した場合は、同じ内容を各生徒のレコードに保存する） |
| created_at | timestamp | 不可 |  | 作成日時 |
| updated_at | timestamp | 不可 |  | 更新日時 |

複合UNIQUE制約：(student_id, lesson_id)

**補講先での出席結果（makeup_status）を元の欠席レコードに持たせる理由**：補講先の授業回に別レコードを作る方式では、30分前補講で補講先が本人の通常授業回（例：次週の自分のクラスの回）になる場合に、複合UNIQUE制約(student_id, lesson_id)により同じ授業回のレコードを2つ作れない。1レコードでは「通常授業に出席したか」と「前回分の補講を受けたか」を区別して表せない（例：通常の時間には来たが30分早くは来なかった）ため、補講の結果は元の欠席レコードの`makeup_status`に記録し、補講先の授業回のレコードは通常授業の出欠だけを表すようにしている。

**振替・補講で「来る側」の生徒**：`makeup_lesson_id`がその授業回を指している出席記録。出席記録・一覧画面では、その授業回の本来の生徒に加えてこれらも表示し（要件定義書5.4）、補講先での出欠は元の欠席レコードの`makeup_status`に記録する。

#### 画面表示ステータスとの対応

出席記録・一覧画面などで表示する6つのステータス（要件定義書5.4）は、次の表を上から順に判定し、最初に当てはまったものを表示する。

| 優先 | 表示ステータス | 条件 |
| --- | --- | --- |
| 1 | 振替済み | status='欠席' かつ makeup_type='振替' かつ makeup_status='出席' |
| 2 | 30分前補講済み | status='欠席' かつ makeup_type='30分前補講' かつ makeup_status='出席' |
| 3 | 欠席 | status='欠席'（補講を予定していてまだ受けていない場合は、補講先の授業回を補足として表示する） |
| 4 | 出席 | status='出席'（is_lateは問わない） |
| 5 | 遅刻 | status=NULL かつ is_late=true |
| 6 | 未定 | status=NULL かつ is_late=false（その授業回のレコードが存在しない場合も含む） |

- 「欠席」を「遅刻」より先に判定するため、遅刻の連絡があった後に結局来なかった場合は「欠席」と表示される
- 「遅刻」は、授業前に保護者から届いた遅刻連絡を事前に表示するためのもの。出席を記録した後は「出席」と表示する
- 「済み」は補講先で実際に出席した（makeup_status='出席'）場合のみ。補講先の日付を過ぎただけでは「済み」にしない

### 凡例

**カーディナリティ（関係性の記号）**

| 記号 | 意味 |
| --- | --- |
| `\|\|` | 1（必ず1つ） |
| `o\|` | 0または1 |
| `}o` | 0以上（多） |
| `}\|` | 1以上（多） |

`A <記号1>--<記号2> B`という書き方の場合、記号1（Aの隣）は「1つのBから見て、Aはいくつあるか」を、記号2（Bの隣）は「1つのAから見て、Bはいくつあるか」を表す。

**関係性のラベル**

| ラベル | 意味 |
| --- | --- |
| has | 親側が子側を持つ、という通常の親子関係 |
| is for | この出席記録が、どの授業回についてのものかという通常の紐付け（lesson_id） |
| is makeup for | 振替・30分前補講として選んだ授業回への紐付け（makeup_lesson_id） |
| records | この出席記録を記録した（対応した）担当スタッフへの紐付け（staff_id） |
