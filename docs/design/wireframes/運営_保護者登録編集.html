WF：保護者登録・編集画面

運営向け／スマホ／full_access のみ

アノテーションの読み方

nav タップで画面遷移する要素
input 入力できる項目
readonly 編集できない表示専用の項目
action 確認の上で実行する操作
danger 削除など取り消しにくい操作
nav
‹ 保護者一覧
保護者を編集
readonly 会員番号：0001
input
未登録の場合、保護者が初回ログイン後に会員番号・初期パスワードでログインし、自身で登録できます。
生徒
nav 佐藤 はると（基礎クラス1組） ›
パスワード
action
パスワードを再発行
実行すると新しい初期パスワードが発行され、画面に一度だけ表示されます。本人への伝達（口頭・チャットなど）は運営が直接行ってください（自動メール送信は行いません）。
danger この保護者を削除する
保存
キャンセル
※未保存の変更がある状態で「‹ 保護者一覧」に戻ろうとした場合は確認ダイアログを想定しています。
※会員番号はシステム発行のため編集不可。新規登録時はこの欄自体が非表示で、保存後に発番されます。
※新規登録時は「パスワードを再発行」の代わりに「初期パスワードが発行されます」という案内のみを表示し、保存後に発行された初期パスワードを一度だけ画面に表示します（削除の項目も新規登録時は非表示）。
※「生徒」欄は表示のみで、この画面からは編集できません（生徒側の登録・編集画面で紐付けを行います）。
※「パスワードを再発行」「この保護者を削除する」はいずれも確認ダイアログを経てから実行します（削除は論理削除＝deleted_at）。
