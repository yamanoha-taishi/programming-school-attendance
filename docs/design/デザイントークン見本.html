Color Swatches

プログラミング教室 出席管理アプリ 配色見本帳

全トークンの色を実際に見て確認するためのページです。決定理由やアクセシビリティのルールはデザイントークン定義書.md、実際の画面に適用した見た目はmockups/フォルダのカラーモックアップを参照してください。

サイト全体の軸になる色。プライマリはボタン・リンク・選択状態など操作の主色、アクセントは強調したい箇所にだけ絞って使います。

未定

Tailwind 4 での定義例

web/resources/css/app.css の @theme に追加するイメージです。

@theme {
  --color-primary: #2E5AAC;
  --color-primary-hover: #24457F;
  --color-primary-tint: #E8EEFA;
  --color-accent: #E8823C;
  --color-accent-hover: #C86A28;
  --color-accent-tint: #FCEADA;

  --color-status-attend: #2F9E4F;
  --color-status-attend-bg: #E8F7EC;
  --color-status-late: #B08000;
  --color-status-late-bg: #FBF3DC;
  --color-status-absent: #D6483F;
  --color-status-absent-bg: #FBEAE8;
  --color-status-transfer: #1E8A8A;
  --color-status-transfer-bg: #E4F5F5;
  --color-status-makeup: #7A4FC9;
  --color-status-makeup-bg: #F1EBFB;
  --color-status-pending: #767C87;
  --color-status-pending-bg: #EEEFF1;

  --font-sans: -apple-system, BlinkMacSystemFont, "Segoe UI",
    "Hiragino Kaku Gothic ProN", "Hiragino Sans", "Yu Gothic", Meiryo, sans-serif;
}
bg-primary / text-primary / border-primary のようなユーティリティクラスがそのまま使えるようになります。
