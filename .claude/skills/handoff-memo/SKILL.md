# 引き継ぎメモ

`memo/検討メモ.md` に、別の場所（Cowork）で見た目を検討する人が、この会話を読まなくてもわかるメモを書く。
`memo/` は Git の管理外なので、コミットはしない。

## 1. 材料を集める

```bash
git branch --show-current
git log --oneline main..HEAD     # このブランチで足したコミット
git status --short
git diff --stat
```

- この会話で決まったこと・保留にしたこと・ユーザーが気にしていたこと
- 関係する画面のファイル（`web/resources/js/pages/...`）と、関係する設計書（`docs/design/` の 画面一覧・遷移図、デザイントークン定義書、モックアップ など）
- `memo/検討メモ.md` が既にあれば先に読み、古くなった内容は直し、まだ有効な内容は残す

## 2. 書く

平易な日本語で、短く。推測は書かない（わからないことは「未確認」と書く）。

```markdown
# 検討メモ

- 更新日：YYYY-MM-DD
- ブランチ：feat/xxx

## 今の状況
- できていること（画面・機能の単位で）
- 途中のこと・未コミットの変更

## 決まったこと
- 内容と、その理由（短く）

## 検討したいこと（見た目）
- どの画面の、どの部分を、何に迷っているか
- 案があれば案A・案Bと、それぞれの良い点・気になる点

## 守ること
- デザイントークン定義書の決まりで関係するもの（例：オレンジは brand-accent 系、状態は色だけで示さない、ボタンの高さ h-11、ライトモードのみ）

## 見るファイル
- docs/design/...
- web/resources/js/pages/...
```

## 3. 報告

書いたファイルのパスと、「検討したいこと」の見出しだけを短く伝える。
